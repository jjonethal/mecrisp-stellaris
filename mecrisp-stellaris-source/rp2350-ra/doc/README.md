# mecrisp-stellaris for rp2350 debugging environment
* Debug interface : Raspberry Pico 2 w with picoprobe software
* openocd for pico2 w

## Pin assignment for pico2w debug interface

|Pin     |Function |
|--------|---------|
|Pin3-GND|GND      |
|Pin4-GP2|SWCLK    |
|Pin5-GP3|SWDIO    |
